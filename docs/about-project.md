# Кофейня-пекарня
Референсы: https://frenchbakery.ru/menu, https://www.bulkabakery.ru/catalog/product/alumette, https://laposte.ru/#aksessuary-sertifikaty, https://lovepirogova.ru/, https://pirogi-skalka.ru/sladkie-pirogi/

## Главная страница:
    1.1 **хедер**: на главном экране будет изображение кофе с печеньками и название магазина. Сверху будет блок навигации с логотипом, главным меню, иконкой корзины. Ссылки на главном меню будут скролить страницу к соответствующему блоку.
    1.2 **блок 1**: Меню товаров. Вначале идут табы из категорий товаров: кофе, печенье, торты, чай и т.д. Ниже, под табами, находятся все товары категорий по секциям. Первая секция соответствует первому табу и т.д. Кликнув на категорию (таб) страница прокручивается к секции с товарами данной категории. Товар состоит из: изображение, название, вес, цена, кнопка + (добавление товара в корзину). Кликнув на кнопку + кнопка заменяется счетчиком количества товара (плюс, минус, количество). Кликнув на изображение товара открывается отдельная страница товара, где будут подробности о товаре. При добавлении товара в корзину, на главном экране, в навигации, возле иконки корзины появляется счетчик - количество выбранного товара.
    1.3 **блок 2**: Отзывы о пекарне в виде слайдера. В слайдере будет изображение товара и отзывы к нему в виде цитаты.
    1.4 **футер**:
       1.1.1 Логотип (ссылка на главную страницу)
        1.1.2 О нас (адрес, время работы)
        1.1.3 Связаться с нами (ссылки на соцсети)
        Все ссылки должны скролится к соответствующим блокам на странице.

## Страница товара
Сверху будет такая же навигация как и на главной странице. Далее идет карточка товара на весь экран. В карточке будет: изображение, название, состав, кбжу, вес, цена, кнопка "В корзину" и счетчик количества товара в корзине. Далее под карточкой внизу будет футер.

## Виджет корзины
При клике на корзину открывается не отдельная страница, а виджет с отображением товаров в ней и стоимости. Количество товаров в корзине можно добавлять/ уменьшать/удалять.

## Завершение покупки
Функционал, что пользователь может завершить покупки, оставив заявку с этими товарами. Данные с заявки попадают в административную панель (или например в телеграм-бот). Пока без платежной системы, но с возможностью добавить такой функционал позже.

## Страница авторизации 
В базовом варианте кнопка авторизации на главной странице не нужна. Авторизация нужна только для администратора и происходит путем ручного захода на страницу `/admin`. Возможно в дальнейшем будет регистрация для пользователей. Способы авторизации через почту, телефон и сторонние ресурсы, по типу google, facebook и т.д. Если телефон/пароль/почта забыт/утерян, то можно использовать телеграмм для восстановления

## Страница административной панели
Страница административной панели с возможностью добавлять/удалять/редактировать товары и видеть заявки пользователей (Доступ только у администратора). Слева будет главное меню, которое будет занимать 20% от экрана, а остальное место - информация. Что будет в меню:
1. Dashboard: 
    - Сводка за день/неделю: количество заказов, выручка, средний чек
    - График продаж по дням/неделям/месяцам
    - Топ продаваемых товаров
    - Новые заказы, требующие обработки
    - Уведомления: новый отзыв и т.д.
2. Заказы:
    - Список всех заказов с фильтрами (новый / в работе / готовится / готов / доставлен / отменён)
    - Карточка заказа: состав, сумма, способ оплаты, статус оплаты, комментарий клиента ("без орехов", "к 18:00")
    - Изменение статуса заказа
    - История заказов конкретного клиента
    - Заказы на конкретную дату (если предзаказ)
3. Товары:
    - Список товаров: чай, кофе, выпечка, торты, десерты
    - Карточка товара: название, фото, описание, цена, вес/размер, состав, аллергены, срок годности
    - Категории (Кофе → Капучино / Латте / Американо)
    - Сезонные/акционные товары (кулич на Пасху, имбирные пряники на Новый год)
4. Клиенты
    - База клиентов: имя, телефон, email, адреса доставки
    - История покупок и сумма всех заказов
5. Отзывы
    - Модерация отзывов о товарах
    - Ответы от имени магазина
6. Управление страницами (О нас, Контакты, Доставка и оплата)
    - SEO-настройки (title, description для страниц)
    - Управление баннерами/слайдером на главной
7. Настройки
    - Пользователи админки и роли (администратор, менеджер заказов)
    - Настройки уведомлений (email/SMS при новом заказе)
