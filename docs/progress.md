## Задача 3

Выполнен пункт 2 плана (`docs/plan.md`) — «Подключение дизайн-токенов из DESIGN.md, базовые
UI-примитивы». Ветка `feature/design-tokens-ui-primitives`.

Токены DESIGN.md (цвета, типографическая шкала с line-height/letter-spacing, радиусы) перенесены
в `tailwind.config.ts`. Шрифт VenusCom из DESIGN.md недоступен как веб-шрифт, а предложенные там
замены (DM Sans/Outfit/Plus Jakarta Sans) не поддерживают кириллицу — критично, так как весь
контент на русском. Вместо них подключена Manrope через `next/font/google` (поддерживает
кириллицу, визуально близка по духу — геометричный гротеск с широким трекингом) под тем же
токеном `--font-venuscom`/`font-venuscom`, чтобы дальнейший код мог просто следовать DESIGN.md
без переименований.

Созданы примитивы `components/ui/Button.tsx` (варианты filled/outline/ghost — Filled CTA,
Ghost/Outlined Nav Item, Ghost Link Button из DESIGN.md), `components/ui/Input.tsx`,
`components/ui/Modal.tsx` (клиентский компонент: `createPortal` с гейтом на маунт по образцу
гидратации корзины из `docs/architecture.md`, закрытие по Esc/клику на фон, блокировка скролла
фона). Проверено вручную в браузере (Chrome DevTools MCP): рендер токенов на главной странице,
открытие/закрытие модалки, возврат фокуса на триггер.

## Задача 4

Выполнен пункт 3 плана (`docs/plan.md`) — «Layout: Header/Nav, Footer». Ветка
`feature/header-footer-layout`.

**Архитектурное решение (отклонение от документированной структуры):** чтобы Header/Footer
показывались только на публичном сайте и не залезали в будущую админку со своим Sidebar-layout
(пункт 14 плана), страницы `page.tsx` и `product/[id]/` перенесены в route group `app/(site)/`
со своим `layout.tsx`. На URL это не влияет (`/`, `/product/[id]` остаются как в
`docs/architecture.md`, раздел 2) — это только про то, какой layout что оборачивает. Корневой
`app/layout.tsx` остался общим для сайта и админки (шрифты, цвета, теперь и конфиг Font Awesome).
`docs/architecture.md` (раздел 1, структура папок) обновлён под новую структуру.

Header — по компоненту DESIGN.md "Top Navigation Bar" (тёмный фон, ~80px, логотип слева,
ссылки справа), активный пункт "Главная" — стиль Ghost/Outlined Navigation Item. Добавлено
мобильное меню (бургер + раскрывающийся список) — в DESIGN.md/about-project.md отдельно не
описано, но без него шапка не работала бы на телефонах. Footer — логотип, "О нас"
(адрес/часы — плейсхолдер, станет редактируемым в задаче 20 "Управление страницами"),
"Связаться с нами" (иконки соцсетей, ссылки-плейсхолдеры `#`). Добавлен `CartIcon` —
пока статичная иконка без счётчика, счётчик и обработчик клика добавятся вместе с cartStore
(пункты 8-10 плана).

Подключён Font Awesome (`config.autoAddCss = false` + прямой импорт стилей в `app/layout.tsx`
по официальной рекомендации docs.fontawesome.com — иначе иконки "мигают" неотстилизованными).

Проверено вручную в браузере (Chrome DevTools MCP): desktop-раскладка, мобильная раскладка
(390×844, открытие/закрытие бургер-меню), ошибок в консоли нет.

**Изменённые/созданные файлы:**
- `app/page.tsx` → перемещён в `app/(site)/page.tsx`

- `app/(site)/layout.tsx` — создан
- `app/layout.tsx` — изменён (конфиг Font Awesome)
- `components/layout/Header.tsx` — создан
- `components/layout/Nav.tsx` — создан

**Новые переменные окружения:** нет.

**Изменения схемы БД:** нет.
