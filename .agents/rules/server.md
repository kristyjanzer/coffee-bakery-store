# Работа с сервером

- Дев-сервер поднимается на порту 3000. Не оставляй фоновые процессы 
(dev-сервер и т.п.) висящими после проверки — завершай их.
- Запросы к внешним API должны оставаться отказоустойчивыми: не ронять страницу при недоступности одного
  источника — используй существующий паттерн `fetchData` (try/catch →
  `null` + `console.error`), а не необработанные промисы.
- Секреты и URL внешних сервисов не хардкодить в коде — использовать
  переменные окружения (`.env.local`, уже в `.gitignore`) и читать их через
  `process.env`.
- Серверные секреты не должны попадать в клиентские бандлы — не используй
  префикс `NEXT_PUBLIC_` для ключей API, которые не обязаны быть публичными.
