# Подключение к MCP-серверам

## chrome-devtools
- Назначение: инспекция и отладка страницы в браузере — DOM, консоль, network, скриншоты, performance
- Когда использовать:
  - При ошибках в консоли
  - Когда нужно посмотреть реальный рендер страницы / состояние DOM, а не гадать по коду
  - При отладке верстки — если что-то "поехало" визуально, сначала смотреть скриншот/computed styles, а не переписывать CSS вслепую
  - Проверка network-запросов при работе с API (валютные курсы, db.json и т.п.)
- Ограничения:
  - Работать только с вкладкой, открытой для текущего проекта
  - Личные вкладки браузера не трогать, не переключаться на них, не читать их содержимое
  - Не использовать для действий на реальных сайтах с моими данными без явного запроса (логины, формы и т.д.) — только для локальной разработки и отладки моих проектов

## context7
- Назначение: подтягивает актуальную документацию по библиотекам/фреймворкам (React, хуки, API)
- Целевая версия: React 19 (актуальная стабильная линейка на 2026 год)
- Когда использовать:
  - Перед объяснением любого React-концепта — сверяться с актуальной документацией, а не с устаревшими примерами из обучения
  - При работе с конкретными библиотеками (axios, React Router и т.д.) — проверять актуальный синтаксис, если есть сомнение в версии
  - Если предлагаешь паттерн/hook — проверить, не deprecated ли он в React 19
- Приоритет: использовать вместо общих знаний в вопросах "как сейчас правильно делать X в React" — версии API меняются быстро
